## 🌟 Overview

This is the bespoke e-commerce web platform engineered for **AVENZ Atelier**, delivering a high-end luxury boutique shopping experience inspired by haute atelier aesthetics, alabaster tones, and warm gold accents.

### ✨ Key Features
- **Curated Catalog & Filtering:** Real-time search and category filtering for Bags, Evening Purses, Butterfly Key Tags, Pouches, and Artisan Jewelry.
- **Enhanced Pricing Presentation:** High-contrast artisan gold pricing typography (`#B8860B`) following modern e-commerce visual hierarchy.
- **Direct WhatsApp Order Pipeline:** One-click WhatsApp consultation & ordering linked directly to customer support.
- **Upload New Piece / Custom Inquiries:** Interactive dropzone modal enabling clients to upload custom reference photos and quote requests.
- **Wishlist & Cart Persistence:** Local storage-backed wishlist with interactive badges.
- **Optimized Performance:** Vanilla HTML5, CSS3 design tokens, and lightweight vanilla JavaScript with asset cache-busting.

## 🚀 Getting Started

To run the site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/D7Systems/Lithumi_Aurelle_Website.git
   ```
2. Open `index.html` in any modern web browser, or serve using a local development server:
   ```bash
   npx serve .
   ```
