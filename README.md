# AVENZ Atelier

E-commerce website for AVENZ Atelier, handcrafted accessories and bags brand.

## Stack
- Vanilla HTML5
- Vanilla CSS3
- Vanilla JavaScript

## Features
- Product catalog with search and category filtering
- WhatsApp ordering integration
- Custom item upload modal
- LocalStorage wishlist
